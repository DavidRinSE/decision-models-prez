05  /  Autoregressive LLM

An LLM loops, one token at a time.

↺ The transformer runs again
for every output token.

JSON output, mid-generation
{"1 escal2 ate3 ":4 ␣"5 ?6

One token per loop. The JSON isn't valid until the last one lands.

Simplified: a key/value cache usually avoids recomputing earlier tokens.
