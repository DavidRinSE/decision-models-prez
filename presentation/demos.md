[jevmeter](https://github.com/ChetasLua/jevmeter)
 - BS Meter overlay on videos, importantly **not a fact checker**. Scores each sentance on five categories for a BS index.
Is this a factual claim?
Is the speaker being evasive?
Does the speaker contradict themselves?
Is this an emotional appeal?
Did the speaker dodge the question?
Rhetorical patterns, not fact checking
[exa web-search](https://demos.exa.ai/jev-web-context)
- Actually a fact checker. Exa is a web search tool, it will go find 6 relevant sources and then add those to the state of the decision model and ask if the evidence supports the claim
